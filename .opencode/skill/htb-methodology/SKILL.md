---
name: htb-methodology
description: Run a disciplined, authorized lab engagement with durable evidence.
---

Treat Hack The Box and other labs as explicitly scoped targets. Record the target,
start time, VPN/interface state, and exclusions in the engagement ledger. Reconnaissance
comes before validation; each finding needs observed output and a source citation.

Route OS-specific work to the matching specialist, verify flags by re-reading their
files, and sanitize secrets before reporting. Never infer a successful exploit from a
plan, a scanner banner, or an agent claim without captured output.
