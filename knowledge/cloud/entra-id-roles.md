If all resources are RBAC/ABAC managed, who manages them? Well this is where Entra ID roles come in. Entra ID roles are applicable on Entra ID resources like users, groups, domains, licenses etc. There are many Administrator roles in Entra ID.

The global administrator is the most well-known and all powerful administrator role
