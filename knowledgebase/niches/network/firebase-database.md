## What is Firebase

Firebase is a backend-as-a-service platform commonly used by mobile and web applications. Its Realtime Database is a cloud-hosted NoSQL database that stores data as JSON and synchronizes changes with connected clients. Applications commonly access it through mobile and web SDKs or its REST interface, while Firebase Security Rules determine which reads and writes are allowed.[\[1\]](#references)

For enumeration and security-testing techniques, see the dedicated HackTricks Cloud guide.[\[2\]](#references)
