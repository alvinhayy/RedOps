## Execute

1. Executes the file tracerpt.exe in the same folder as WFMFormat.exe. If the file dumpfile.txt (any content) exists in the current working directory, no arguments are required. Note that WFMFormat.exe requires .NET Framework 3.5.

```
WFMFormat.exe
```
