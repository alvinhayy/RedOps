## Summary

This article outlines the methods on bypassing Google Play Protect warnings and how to install blocked APKs on Zebra Android mobile computers.

## Issue/Question

- How can I bypass Google Play Protect warnings to install an APK on Zebra Android mobile computers?
- What are the steps to disable Google Play Protect manually?
- Is there a way to install apps blocked by Google Play Protect on Zebra mobile computers?
- App won't install without manually allowing install
- Is there a way to block the warning?

## Applicable To

Zebra Android mobile computers

## Resolution / Answer

### Play Protect Message for APK Installation

When installing an APK, the Play Protect warning appears because Google enforces this for apps developed with an SDK API two versions lower than the device's Android version. For example, API 33 devices will warn for API 30 or lower apps. See Google's Developer Guidance for Google Play Protect Warnings.

> NOTE: Using StageNow or an EMM does not bypass the "Unsafe app blocked" warning. To install, manually tap More details and then Install anyway.

Play Protect can be disabled manually from the Play Store app (3-dot menu > Play Protect > Gear settings menu > Scan apps with Play Protect: Un-Check). This cannot be deployed via StageNow or an MDM.

### Bypassing Google Play Protect Warnings

Using StageNow:

Disable Play Store to disable Play Protect. See article: Disabling Automatic Google Play Store Updates via StageNow.

Example MX XML:

```xml
<wap-provisioningdoc>
  <characteristic version="9.1" type="AppMgr">
    <parm name="Action" value="DisableApplication" />
    <parm name="Package" value="com.android.vending" />
  </characteristic>
</wap-provisioningdoc>
```

- Temporarily disable Play Store if needed for other apps.
- Disable Play Store - package name: `com.android.vending`.
- Install the APK.
- Enable the Play Store.

Example MX XML:

```xml
<wap-provisioningdoc>
  <characteristic version="9.1" type="AppMgr">
    <parm name="Action" value="DisableApplication" />
    <parm name="Package" value="com.android.vending" />
  </characteristic>
  <characteristic version="9.1" type="AppMgr">
    <parm name="Action" value="Upgrade" />
    <parm name="APK" value="/sdcard/MyApplication.apk" />
  </characteristic>
  <characteristic version="9.1" type="AppMgr">
    <parm name="Action" value="EnableApplication" />
    <parm name="Package" value="com.android.vending" />
  </characteristic>
</wap-provisioningdoc>
```

Using an EMM:

For new devices:

1. Enroll in EMM.
2. Disable `com.android.vending` using AppMgr.
3. Reboot.
4. Toggle ENSURE_VERIFY_APPS restriction.
5. Install or Update apps without warnings.

For enrolled devices:

1. Create an EMM profile to Disable `com.android.vending` using AppMgr.
2. Reboot.
3. Toggle ENSURE_VERIFY_APPS restriction.
4. Install or update applications will not have any Play Protect warnings.

ADB command:

```bash
adb shell settings put global verifier_verify_adb_installs 0
```
