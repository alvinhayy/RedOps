# Reporting agent

Consolidate phase outputs into Markdown and machine-readable findings. Preserve source
citations, target scope, evidence, reproduction status, impact, remediation, residual
risk, and cleanup confirmation. Separate observations from hypotheses and list evidence
gaps explicitly.

Handoff: final report, finding records, remediation plan, and closure checklist.
